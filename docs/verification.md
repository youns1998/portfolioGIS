# 실행 검증 기록

검증일: 2026-10-26 / Windows x64

`src/` 이동과 화면 파일 분리 후 Python 21개와 브라우저 10개 검사를 통과했습니다. DB 대조 기록의 입력·분석 결과는 그대로 유지했습니다.

| 단계 | 실행 환경 | 결과 |
|---|---|---|
| 단위·출력 테스트 | Python 3.13.15 | 21개 통과 |
| 분석 | 기준일 2026-10-25 / 반경 750m | 시설 36 / P1 7 / 반경 밖 19 |
| HTML 지도 | Chrome / 1440px·390px | 10개 검사 통과 |
| DB 대조 | PostgreSQL 17.11 / PostGIS 3.6.2 | 36행의 ID·거점·판정·점수·등급 일치 |
| 거리 모델 비교 | 구면 Haversine / PostGIS geography | 최대 차이 3.4849m / 표본 허용치 5m |
| GeoPackage | SQLite integrity_check / 피처 헤더 | 통과 |
| QGIS 프로젝트 | XML 구문·레이어·상대 경로 | 통과 / 데스크톱 열기 미검증 |

`output/database-check.json`은 실제 psql 실행으로 생성했습니다. 이 값은 고정된 가상 표본에서의 모델 비교입니다. 다른 위치·반경에는 5m 허용치나 판정 일치를 일반화할 수 없습니다.

브라우저 검사는 `run.py serve`가 제공하는 실제 생성 파일에서 수행했습니다. 스크린샷은 `docs/images/`에 있습니다. 네트워크 지도 서비스 없이 동작하도록 HTML과 SVG를 함께 생성합니다.

입력 검증은 자기 교차의 대표적인 경우를 거절하지만 폴리곤 간 모든 위상 관계까지 검사하지 않습니다. 실제 외부 데이터는 좌표계와 출처·이용 조건을 확인하고 GIS 전용 검증 도구로 정제한 뒤 입력해야 합니다.
